# 기억 중심 연습 모델

## 사용 흐름

- 홈에서 오늘 복습, 취약 카드, 전체 카드 중 선택한다. 오늘·취약 복습은 무작위 최대 10장이다.
- 먼저 질문만 보고 말한 뒤 정답을 확인한다. 첫 단어 힌트를 쓰면 ‘알았음’을 눌러도 ‘애매함’으로 기록한다.
- ‘몰랐음’ 카드는 해당 묶음 마지막에 한 번 더 나온다. 계속 틀려도 세션이 무한히 늘어나지 않는다.
- 내 질문·영어 답변 카드를 추가할 수 있다. 주제 필드와 개인 연결 메모로 맥락을 남긴다.
- 내 답변 연습에도 오늘/취약/암기 완료 필터, 백지 테스트, 연결 메모, 세 가지 기억 평가를 제공한다. 기존 학습 완료 체크와 기억 평가는 별개다.
- 카드 듣기는 한국어 질문을 읽고 5초 후 영어 답변을 읽는다. 듣기 사용은 힌트 사용으로 간주한다. 화면 이동 시 재생을 중지한다.

## 저장

로그인이나 서버 DB 없이 현재 브라우저 localStorage에 저장한다. 브라우저 데이터 삭제 시 없어지며 다른 기기로 자동 동기화되지 않는다.

- `opic_custom_cards`: `{ id, front, back, topic }` 배열. ID는 `custom:` 접두사의 UUID다.
- `opic_srs`: 항목 ID를 키로 하는 객체. 기존 레슨 카드 ID는 유지한다. 답변은 `answer:D01`처럼 구분한다.
- 상태 필드: `interval`(일), `ease`(기존 호환), `due`(밀리초), `streak`, `level`, `mastered`, `mnemonic`, `history`.
- `history`: 최근 50회 `{ at, rating }`. rating은 0=못 떠올림, 1=힌트 필요, 2=독립적으로 떠올림이다.
- 옛 상태의 interval/ease/due는 유지하고 새 필드에는 기본값을 적용한다. 과거 성공 횟수는 추측하지 않는다.

## 일정 규칙

단순 단계형 일정이며 개인의 망각 확률을 계산하는 모델은 아니다. 다음 예정일 이후, 이전 평가와 다른 날짜의 독립 회상만 연속 성공으로 센다. 같은 날 반복 성공은 단계를 올리지 않는다.

독립 성공 간격은 1 → 3 → 7 → 14 → 30일이다. 세 번 연속 성공하면 일상 복습에서 제외한다. 이후 전체 목록에서 직접 연습하면 더 긴 간격으로 진행할 수 있다. 못 떠올리거나 힌트가 필요하면 완료를 해제하고 연속 성공을 초기화하며 다음 복습을 1일 뒤로 잡는다.

## 구현 범위

오늘 복습 안내는 앱 홈에서 제공한다. 앱이 닫힌 상태의 예약 Push 알림은 구현하지 않았다. TTS 지원 여부는 실행 시 확인한다. STT 자동 정답 판정과 마인드맵 그래프·이미지 생성은 포함하지 않았다. 말하기는 자가 평가, 연결 학습은 주제와 개인 메모로 지원한다.
