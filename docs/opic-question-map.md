# 오픽 시험지 — 28쪽 질문의 4카테고리 분류

원본: [오픽 시험지.pdf](오픽%20시험지.pdf). PDF 본문의 이미지와 추가 텍스트를 함께 확인했습니다. 같은 페이지에서 반복되는 질문은 묶되, 시간·대상·요구 행동이 다른 질문은 구분했습니다. `S1Q2`는 SET 1의 Q2입니다.

**D = 묘사 / H = 습관 / P = 과거 경험 / C = 비교.** 이 네 가지는 이번 학습용 분류입니다. 사회 이슈 설명은 `D·의견`, 과거의 상태만 설명하면 `P·과거묘사`, 미래 희망 활동은 `H·계획 응용`으로 표시해 일반적인 개인 묘사·습관과 구분했습니다. 복합 질문은 필요한 유형을 모두 표시했습니다.

질문에 ‘묘사’라는 말이 있어도 과거 사건이면 P, 변화면 C입니다. ‘기억에 남는 영화/호텔’처럼 **대상 자체를 소개**하는 질문은 D가 중심이고, 관람·투숙 중 일어난 사건을 요구할 때 P입니다. 뉴스 요약은 `P·뉴스`로 표시했으며, 개인 경험담과 달리 실제 보도 내용·시점이 필요합니다.

아래 답변 번호는 [개인 답변집](opic-personal-workbook.md)의 해당 부분으로 연결됩니다. **보충**은 기존 메모에 필요한 사실이 없다는 뜻입니다. 답변 번호가 있어도 뒤의 조건을 확인합니다.
